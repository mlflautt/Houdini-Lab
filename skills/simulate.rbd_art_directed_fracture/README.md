# `simulate.rbd_art_directed_fracture@1.0.0`

Builds one bounded native concrete destruction graph with three retained human-selectable impact
profiles. The selected profile feeds pinned `RBD Material Fracture::4.0`, RBD Configure, and one
proxy Bullet Solver. Bullet Simulation Points pass through a configured but unwritten File Cache
and reconstruct the editable polygon pieces with Transform Pieces.

The default validates 48 frames, at most 5,000 pieces, stable finite transform attributes, material
constraint breaking, meaningful motion, topology-preserving reconstruction, clean Houdini
messages, timeline restoration, and zero implicit cache files. Optional visual capture requires an
explicit viewer, viewport, and camera, then uses deterministic analysis and a hashed advisory
critique packet without running a model or choosing a winner.

See [`docs/rbd-art-directed-fracture.md`](../../docs/rbd-art-directed-fracture.md).
