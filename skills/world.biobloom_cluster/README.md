# world.biobloom_cluster

**Clustered procedural alien botanical form.** Composes `scatter.cluster_points` + `sweep_petals`
recipes into a blooming structure. Deterministic by seed.

## Controls
- `seed` (int)
- `cluster_count` (3–200)
- `growth_bias` (0–1)
- `detail_level` (draft | preview | final)

## Verification
Graph / data / visual checks per `skill.yaml`. Non-commercial (Apprentice-aware).
