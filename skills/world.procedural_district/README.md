# Procedural District

`world.procedural_district@1.0.0` builds a registered native-SOP building source, distributes
declared numeric controls through a native Wedge TOP, caches one bounded building per work item,
and assembles the successful immutable caches into both a spatial district and an equal-scale
comparison gallery.

The default is twelve lots, one local scheduler slot, foreground execution, and no automatic
ranking. Block, terrace, and needle are descriptive massing profiles rather than architectural or
engineering claims. Every cache retains its lot ID, seed, profile, placement, hash, and empty human
rating so an artist or later Hermes session can continue from the graph and manifests.

The skill does not require Sprint 15 terrain output. A later composition may replace the flat
ground branch or modify the recorded placement transforms using a validated terrain/scatter
contract without changing the lot-generation recipe.
