## Delivered contract

Lane A delivers a Houdini-independent parser, validator, and canonical hasher for
`hermes.houdini.project.v1`. It accepts only one explicit YAML mapping, uses `yaml.safe_load`, and
returns JSON-shaped intent with source list order preserved. It confines the specification and all
embedded root/reference/artifact paths beneath an explicit absolute project root, then serializes
those paths relatively so checkout paths do not enter the hash.

The public API is exactly:

```text
normalize_project_spec(value: Mapping, *, project_root: str | Path) -> dict
load_project_spec(path: str | Path, *, project_root: str | Path) -> dict
project_spec_sha256(normalized: Mapping) -> str
```

The implementation does not discover capabilities, resolve adapters, compile stages, import or
start Houdini, mutate/cook/render a graph, write project artifacts, rank variants, or fill human
decisions.
