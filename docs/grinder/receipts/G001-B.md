## Fixture and budget contract

`build_acceptance_fixtures` requires a caller-supplied unused absolute root. It builds readable
native SOP, Solver SOP, one-child ROP Geometry TOP, explicit OBJ camera, Solaris, and managed Karma
ROP graphs inside one undo group. Every reported managed node has `hermes_id`, `hermes_role`, and
`hermes_created_by`. The builder preserves the caller's HIP name, saves a rebuildable `.hipnc`, and
does not query geometry, cook a display chain, launch a child, capture pixels, or render.

Every tier requires all explicit ceiling fields. Frozen maximums are:

- 10,000 points
- 8 frames
- 256 MiB observed memory
- 256 MiB artifact bytes
- 640x360 viewport/render
- 16 samples
- 120 seconds
- one PDG work item

Paths are exclusive: the artifact root must be unused, and PDG, viewport, Karma output, and Karma
log adapters refuse overwrite.

`errors`. It imports no Lane A schema and writes no unified summary.
