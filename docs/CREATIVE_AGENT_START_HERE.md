# Creative Agent Start Here — Houdini Lab

## Telos

Houdini Lab is an agentic creative studio, not merely a Houdini automation library. Its purpose is
to let a capable agent enter a project, understand human intent, construct readable procedural
systems, show authentic visual and temporal alternatives early, accept precise creative direction,
and leave both an editable artwork and reusable knowledge for the next agent.

The graph is the creative instrument. Automation exists to make ambitious iteration dependable,
not to replace human judgment or hide procedural thinking.

## Boundless possibility, bounded execution

Creative possibility may remain broad. Every individual action must still be explicit and bounded:
named graph changes, exact scenes and outputs, declared frames, cook/render scope, resource ceilings,
checkpoint, cancellation, rollback, and evidence. A small safe experiment is the normal way to
explore a large idea.

## Universal creative loop

Every harness follows this loop for creative work:

```text
enter and inspect
  -> restate intent and unresolved questions
  -> propose 2-3 meaningfully different visual hypotheses
  -> build the cheapest authentic previews that can test them
  -> present alternatives in stable order without ranking
  -> bind the human's exact critique to exact artifacts
  -> translate critique into bounded revision hypotheses
  -> create non-overwriting before/after evidence
  -> save a readable graph and portable continuation handoff
  -> promote genuinely reusable methods into skills/recipes/docs
```

Do not spend an entire creative cycle on horizontal infrastructure if one thin vertical slice can
exercise the same architecture while producing something the owner can judge.

## Entry protocol for any agent

1. Read `AGENTS.md`, `docs/architecture.md`, this file, the active project specification, its latest
   creative handoff, and the relevant registered skill/recipe manifests.
2. Inspect the real repository, Houdini build/license, current scene or fresh-scene requirement,
   capability catalog, outputs, budgets, and pending approvals. Never infer state from conversation
   alone.
3. State what is verified, what is an artistic hypothesis, what remains unselected, and what action
   would first create useful visible evidence.
4. Preserve supplied references, alternatives, exact user words, null decisions, seeds, candidate
   identities, and rejected lineage.
5. Produce a dry manifest before live work. Obtain exact authority for graph edits, cooks,
   simulation, viewport, Karma, plugins, external models, and downstream transfer independently.
6. Stop and present artifacts whenever human taste is the next dependency. Do not simulate consent
   by choosing a winner.

## Creative method stack

An elite Houdini capability teaches and composes methods across these layers:

| Layer | Questions the agent must expose as editable controls |
|---|---|
| Intent | What should the work evoke, communicate, reveal, or transform? What remains ambiguous? |
| Form | What are the primary/secondary masses, silhouette, scale hierarchy, density, repetition, focal region, and negative space? |
| Generative grammar | Which rules produce coherent variety? Which constraints prevent noise, sameness, collapse, or unbounded growth? |
| Time | What initiates change? Where are anticipation, acceleration, pause, contrast, recurrence, phase, and resolution? |
| Interaction | Which fields, collisions, constraints, feedback loops, or dependencies make systems affect one another? |
| Surface | How do material scale, roughness, transmission, emission, displacement, and color relationships reveal form? |
| Atmosphere and light | What establishes depth, separation, mood, scale, and legibility? |
| Camera and edit | What view, lens, movement, duration, and comparison layout let a human judge the intended phenomenon? |
| Variation | Which parameters create meaningfully different lineages rather than cosmetic noise? |
| Critique | Which findings are mechanical defects, artistic hypotheses, exact human preferences, or still unresolved? |

No default is called masterful merely because it is deterministic. Mastery is demonstrated through
control, visual specificity, meaningful variation, readable construction, and responsive revision.

## Minimum visible artifact contract

For a generative form study:

- at least two meaningfully different authentic alternatives;
- one stable-order comparison and individual inspectable views;
- readable graph evidence and exact seeds/controls;
- geometry and framing mechanics; and
- null human preference fields until review.

For motion, simulation, or transformation:

- an authentic sequence or flipbook with explicit frame/time identity;
- nonduplicate temporal evidence and representative sampled frames;
- the source and resulting motion graph kept editable;
- bounded cook/cache/render metrics; and
- no claim based only on a still image.

For a project milestone:

- project-confined non-overwriting scene and artifacts;
- graph, data, visual, and human evidence reported separately;
- at least one owner review opportunity;
- before/after lineage for any claimed refinement; and
- a portable handoff another agent can resume without hidden UI or conversation state.

## Creative knowledge promotion

Promote a pattern only after it has participated in an authentic work and its controls/failure modes
are understood. A promoted creative method should contain:

- narrow purpose and applicable contexts;
- native graph/recipe source and stable contracts;
- `creative_levers`: what each major control changes perceptually;
- useful ranges, interactions, seeds, and resource effects;
- visual/temporal examples with provenance;
- common failure modes and recovery strategies;
- composition, timing, material, lighting, and camera considerations where relevant;
- mechanical validators that do not rank taste;
- Apprentice/license/build boundaries; and
- a continuation example showing how a human can keep editing the graph.

Project-local feedback remains project-local unless the owner explicitly promotes it. Universal
mechanical facts may be reused; a person's preference for one artifact cannot silently become a
global aesthetic rule.

## Default answer to “show me something”

Find the shortest registered path to authentic pixels, create two or three bounded alternatives,
and present them. If the required live authority is missing, produce the exact dry manifest and ask
for that authority immediately. Do not answer a request for creative output with another abstract
roadmap unless a verified technical blocker makes the roadmap necessary.
