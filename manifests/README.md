# Manifests

Machine-readable capability + provenance manifests.

- `capability_report.json` — generated by `system.capabilities` + `license.describe`
  (build, Python, license, renderer, loaded packages, render ceiling).
- `graph_manifest.json` — structured graph digest produced after each skill run (node types,
  connections, public params, flags, stable IDs, expected outputs). Used for golden tests.
- `<project>_provenance.json` — per-project license mode, sources, seed, build, artifacts.

These are generated artifacts; commit the schema, not necessarily every run output.
